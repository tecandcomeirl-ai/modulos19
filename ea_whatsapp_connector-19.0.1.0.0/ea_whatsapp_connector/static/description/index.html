Features

Everything you need to send & receive WhatsApp messages, share business documents, manage multi-number accounts, and analyze message delivery right inside Odoo.

WhatsApp-Style Chats Screen

Dedicated WhatsApp > Chats workspace with contact list sidebar, profile pictures, unread badges, conversation threads, live bus updates, and instant media attachment sharing.

Live QR Code Pairing

Pair any phone number instantly by scanning a QR code inside the Odoo Account form. No Meta Business API registration, template approval, or external app verification required.

Multi-Account & Multi-Company

Connect one or more WhatsApp accounts to different companies or sales teams. Set default accounts per company and control user vs administrator access permissions.

Send from Any Document

Send WhatsApp messages directly from Contacts or any document linked to a partner. Sent messages and attachments are automatically logged on the record's chatter.

Auto Contact Creation

Incoming messages from unknown numbers automatically create new contacts in Odoo, fetch WhatsApp profile pictures, and log inbound text, audio, images, and files.

Delivery Status Tracking

Real-time delivery status updates: single tick (Sent), double tick (Delivered), and blue double tick (Read). Red exclamation (!) indicates failure with click-to-retry.

Interactive Dashboard

Monitor KPIs (Sent, Delivered, Read, Received, Failed), delivery funnel conversion rates, daily activity charts, recent messages feed, and top contacts in one place.

Quotation & Sales Order Bridge

Send Quotations and Sales Orders with pre-filled message text, customer portal accept links, and auto-attached QWeb PDFs. Updates quotation state to Quotation Sent.

Invoicing & Credit Note Bridge

Send posted Invoices and Credit Notes with amount due, due date, online payment link, and PDF invoice attachment directly to customer WhatsApp.

7-Day Related Document Routing

When a contact replies on WhatsApp within 7 days, the response is automatically logged directly onto the chatter of the Sales Order or Invoice last sent.

Security & Access Levels

Configured with Odoo security groups: WhatsApp / User (send & view messages) and WhatsApp / Administrator (create accounts, pair QR, manage API keys).

Lightweight Node.js Gateway

Shipped in the sidecar/ folder. Uses Node.js & Baileys library with session persistence so credentials restore automatically after restarts.

Is Meta Business API approval or template registration required?
No. The module uses the WhatsApp Web protocol via a lightweight Node.js gateway (Baileys). You pair your WhatsApp number simply by scanning a QR code inside Odoo — exactly like connecting WhatsApp Web on your browser.
Are there per-message costs or subscription fees?
No per-message fees! Because messages are transmitted through your paired phone number via the sidecar gateway, there are zero conversation category fees or third-party message charges.
Which Odoo versions are supported?
This module is built for Odoo 19 & 20 Community and Enterprise editions. It depends on standard base modules (mail and phone_validation).
How are session credentials stored & restored?
Session credentials are stored in the gateway's DATA_DIR directory (`./sessions`). The gateway automatically restores and reconnects active sessions whenever the server restarts.
Can I connect multiple WhatsApp numbers?
Yes. You can add as many WhatsApp accounts as needed under WhatsApp > Configuration > Accounts. Assign default accounts per company and manage permissions per user.
